## Becoming a maintainer

We welcome new maintainers. After consistent, high-quality contributions over time
(triage, reviews, fixes), an existing maintainer will propose adding you in a PR
to this file. Decisions are made by lazy consensus among current maintainers.

## Security

Security issues should be reported via GitHub's private vulnerability disclosure
or by emailing `security@x402cloud.ai` — see [SECURITY.md](./SECURITY.md). Do not
file public issues for security vulnerabilities.
